# Claude2Blender

Personal/small-group product-render addon for Blender 5.x+, distributed through
the owner's GitHub fork. Users steer material, lighting and camera work through
their own Claude or Codex CLI sign-in; Claude is the default. Scene proposals are
reviewed and applied explicitly through the existing guards and session History.

The local companion supports visual storyboard, notes, comparison and delivery
tasks while Blender remains authoritative. It is a working tool, not a marketing
site. No external fonts, tracking, hosted services or licensed asset bundles.
Source of these decisions: the owner-supplied ASTRA brief, revision 3.
